## 1. 프로젝트 개요 (Project Overview)

### 1.1 게임 컨셉 & 비전
* **타이틀**: 초특훈! 무한피칭 (일본어: 超特訓！無限ピッチング / 영어: Infinite Pitcher)
* **장르**: 원터치 순발력 아케이드 야구 피칭 퍼즐
* **비주얼 & 사운드 톤**: 80~90년대 쇼와 레트로 일본 열혈 스포츠 아케이드 감성 (강렬한 원색, 네온 포인트, 굵은 검은색 외곽선 카툰 그래픽, 경쾌한 타격음과 아케이드 BGM)
* **플랫폼**: 모바일 웹(HTML5 / PWA) 및 하이브리드 모바일 앱(Capacitor 기반 iOS / Android)
* **기준 해상도**: `1080 × 1920` (9:16 세로 풀스크린, Safe-Area Inset 및 Dynamic Visual Viewport 대응)

### 1.2 핵심 재미 요소 (Core Pillars)
1. **초직관적 원터치 조작**: 좌우 드래그(또는 키보드 방향키)로 투수 위치를 맞추기만 하면 공은 일정 템포로 자동 투구된다.
2. **점진적 가속과 극한의 몰입감**: 점수가 오를수록 투구 쿨다운이 빨라지고, 4가지 마구 기믹(파이어볼·미러볼·스트라이프볼·플래시볼)이 시각과 인지를 흔든다.
3. **글로벌 랭킹 & 8인 실시간 서바이벌**: 개인 최고 기록(TOP 1000) 경쟁뿐 아니라, 최대 8명이 동일한 숫자판 시드로 동시에 겨루는 실시간 배틀로얄을 제공한다.

## 3. 게임 메카닉 및 밸런스 설계 (Core Mechanics)

### 3.1 기본 규칙 (Number Matching)
1. 각 행은 **10개의 숫자**(1~10, 11~20, 21~30 ...)가 무작위 순서로 섞여 배치된다.
2. 플레이어는 **1번부터 오름차순으로 다음 정답 숫자(`nextExpectedNumber`)** 아래로 투수를 이동시켜 자동 투구되는 공을 맞혀야 한다.
3. **성공**: 점수 `+1`, 해당 블록 파괴, 다음 숫자 활성화, 블록판이 1줄 아래로 스크롤.
4. **실패**: 다른 숫자 블록을 맞히거나 빈 공간(아무 블록도 맞히지 못함)으로 공이 통과하면 즉시 **게임오버(Game Over)**.

### 3.2 투구 속도 가속 밸런스 (`getPitchInterval`)
점수(목표 번호 `n`) 또는 배틀 페이즈에 따라 투구 쿨다운(ms)이 빨라지며 긴장감을 극대화한다.

#### ① 개인 기록 모드 (나홀로 특훈)
| 구간 (다음 목표 번호 `n`) | 투구 간격 (Interval) | 체감 난이도 |
| :--- | :---: | :--- |
| `1 ~ 30` | **1,000 ms** (1.0초) | 입문 / 워밍업 |
| `31 ~ 130` | **900 ms** (0.9초) | 기본 템포 |
| `131 ~ 230` | **800 ms** (0.8초) | 가속 시작 |
| `231 ~ 330` | **700 ms** (0.7초) | 고속 영역 |
| `331 ~ 430` | **600 ms** (0.6초) | 초고속 영역 |
| `431 ~ 530` | **500 ms** (0.5초) | 극한 반사신경 |
| `531 이상` | **400 ms** (0.4초) | 마스터 한계 구간 |

#### ② 온라인 대전 모드 (리그별 5단계 페이즈 투구 간격)
모든 참가자는 소속 리그(승점 기준 자동 배정)에 따라 공통 투구 간격(ms)으로 경쟁하며, **페이즈 전환 시마다 균일하게 100ms씩 가속**된다.

| 페이즈 | 진입 조건 | 🥈 일반 리그 (`600 ~ 1,200 PT`)<br>*(1,200ms 시작 · 100ms씩 감소)* | 👑 마스터 리그 (`1,200 PT 초과`)<br>*(1,000ms 시작 · 100ms씩 감소)* | 발동 기믹 & 특징 |
| :---: | :--- | :---: | :---: | :--- |
| **Phase 1** | 게임 시작 (`1 ~ 10번`) | **`1,200 ms`** (1.20초) | **`1,000 ms`** (1.00초) | 일반 투구 워밍업 |
| **Phase 2** | `11번` 도달 | **`1,100 ms`** (1.10초) | **`900 ms`** (0.90초) | 🔥 **파이어볼** 개막 |
| **Phase 3** | 생존자 `5명 이하` OR `51번` 도달 | **`1,000 ms`** (1.00초) | **`800 ms`** (0.80초) | 🪞 **미러볼** 개막 (좌우 반전) |
| **Phase 4** | 생존자 `3명 이하` OR `91번` 도달 | **`900 ms`** (0.90초) | **`700 ms`** (0.70초) | 🦓 **스트라이프볼** 개막 (행 교차 반전) |
| **Phase 5** | 최후 `2인 1:1 결승` OR `131번` 도달 | **`800 → 700 → 600 ms`** | **`600 → 500 → 400 ms`** | ⚡ **플래시볼** 개막 (숫자 점멸) + 결승 서든데스 가속 |

| ⚡ **플래시볼** (`flashball.png`) | `301번` 도달 시 | **Phase 5** 진입 시 | 번개 예고 연출 후 **숫자가 일정 주기로 깜빡이며 사라졌다 나타나는** 블라인드 기믹이 적용된다. |

## 5. 게임 모드 상세 기획 (Game Modes)

### 5.1 ⚡ 세계 8인 배틀 (World 8-Player Battle)
* **진입 방식**: 메인 화면 `[⚡ 세계 8인 배틀]` 클릭 → 대기실 진입 → 유저가 직접 **`[⚡ 매칭 시작]`** 버튼을 눌렀을 때 매칭 시작 (자동 매칭 방지).
* **실제 유저 우선 매칭 알고리즘**:
  * Firebase RTDB 보안 규칙(`$roomId.length === 4`)을 준수하는 4글자 원자적 큐 키 **`_QMP`** (`battles/_QMP`) 및 `isPublicWaiting` 인덱스 쿼리를 병행.
  * 동시 접속 또는 **20초(`QUICK_MATCH_WAIT_SECONDS = 20`)** 탐색 윈도우 내에 다른 유저가 매칭을 시작하면 봇 방이 아닌 **실제 유저가 대기 중인 방에 즉시 합류**.
  * 20초가 경과하거나 8명이 모두 차면, 남은 빈자리만큼 AI 챌린저 봇(국가별/티어별 봇 풀)을 자동 투입하여 **항상 8인 풀방**으로 시작.
* **동기화 공정성**: 방 생성 시 공통 `boardSeed`를 공유하여 8명 모두가 **완전히 동일한 숫자 배치판**에서 실력을 겨룸.
* **승패 및 관전 시스템**:
  * 1명만 남거나(2등 탈락 시 1등 즉시 우승 확정) 전원 탈락 시 경기 종료.
  * 먼저 탈락한 플레이어는 즉시 로비로 나가거나, 남은 생존자들의 실시간 경기를 끝까지 **라이브 관전** 가능.
  * 경기 종료 후 최종 순위표 노출 및 5초(`ROOM_AUTO_CLOSE_SECONDS = 5`) 카운트다운 후 방 자동 정리.

### 5.2 👤 나홀로 특훈 (Solo Practice Mode)
* 개인 최고 기록(Personal Best) 경신 및 글로벌/국가별 TOP 1000 랭킹 등재가 목표인 싱글 플레이 모드.
* 최초 31번 파이어볼 돌파 전까지는 초보 구간 배려를 위해 무제한 무료 플레이 가능.

### 5.3 👥 친구와 특훈 (Friend Room Mode)
* **방 만들기**: 4자리 숫자 방 코드 자동 발급, 방장이 친구 입장 확인 후 `[게임 시작]` 클릭 시 시작 (최소 2명 이상).
* **코드 입력 입장**: 친구가 공유한 4자리 코드를 입력하여 해당 방에 즉시 합류.
* **UI 분리**: 친구와 특훈 화면에서는 `빠른 매칭` UI를 숨기고 방 코드 공유 및 코드 입력에 집중, 반대로 세계 8인 배틀 화면에서는 방 코드 입력/생성 UI를 숨김.

## 6. 8인 배틀 성장 & 동기부여 시스템 *(확정 기획 · 구현 예정)*

추가 서버 비용 없이 클라이언트(`localStorage`)와 기존 `users` 복원 데이터만으로 8인 배틀의 승부욕과 수집 재미를 극대화하는 성장 시스템.

### 6.1 영구 배틀 계급(티어) & 제로섬 승점 시스템
* **원칙**: 시즌 초기화 없는 **영구 누적 레이팅** 방식이며, 인플레이션을 방지하기 위해 **완전 대칭 제로섬(Zero-Sum) 가감점**을 적용한다.
* **시작 점수 & 하한선**: 모든 유저는 **기본 `1,000 PT`**로 시작하며, 연패하더라도 **최저 `600 PT` 이하로는 떨어지지 않는다.** (하한 `600 PT` / 상한 `9,999 PT`, 점수 하락 시 계급 **강등 적용**)

#### ① 순위별 승점 변동표 (합계 `0`)
| 최종 순위 | 승점 변동 | 비고 |
| :---: | :---: | :--- |
| **1위** | **`+20 PT`** | 우승 |
| **2위** | **`+10 PT`** | 준우승 |
| **3위** | **`+5 PT`** | 상위권 입상 |
| **4위** | **`0 PT`** | 현상 유지 |
| **5위** | **`0 PT`** | 현상 유지 |
| **6위** | **`-5 PT`** | 하위권 감점 |
| **7위** | **`-10 PT`** | 조기 탈락 감점 |
| **8위** | **`-20 PT`** | 최하위 광탈 대폭 감점 (하한 600 PT 보호) |

#### ② 리그 & 계급 구간 (초기 2단계 운영)
초기 유저 분산과 매칭 지연을 방지하기 위해 **1,200점을 기준으로 2개 리그(매칭 풀)로 심플하게 이원화 운영**하며, 추후 유저 풀 증가 시 상위 티어를 세분화한다.

| 리그 / 계급 | 승점 구간 (`PT`) | 매칭 큐 키 | 설명 및 UI 노출 |
| :--- | :---: | :---: | :--- |
| **🥈 일반 리그 (스탠다드)** | `600 ~ 1,200` | `_QP1` | **기본 시작 등급 (`1,000 PT`)** 포함. 입문 및 일반 유저 매칭 풀 (최저 600점 보장) |
| **👑 마스터 리그 (프로)** | `1,200 ~ 9,999` | `_QP2` | **1,200점 돌파 고수 전용 매칭 풀**. 점수 하락 시 일반 리그로 강등 |

### 6.4 리그별 1,000명 봇 풀 & 인간적 하방 실수 분포 시스템
* **서버 비용 0원 아키텍처**: 1,000명의 봇 데이터를 Firebase 서버에 저장하지 않고, **클라이언트 메모리에서 시드 기반 결정적 알고리즘으로 즉시 생성**한다. (네트워크/DB 추가 트래픽 제로)
* **하방 편향(Downward Skewed) 인간적 실수 공식**:
  * 기존 봇의 문제점인 "기계처럼 정해진 점수까지 완벽히 생존"하는 현상을 제거.
  * 실제 인간 플레이어처럼 **기대 점수 근처에 도달하기 전에 초반(Phase 1~3)에서 손가락이 꼬여 어이없이 실수로 탈락하는 비율을 높이는 멱급수 난수 공식** 적용:
    $$\text{목표 점수} = \text{기대 점수} - (\text{Random})^{2.2} \times (\text{기대 점수} - \text{Floor}) + \text{LuckyBonus}$$
* **리그별 봇 구성**:
  * **일반 리그 봇 (1,000명)**: 승점 600~1,180 PT, 판수 10~80판, 승률 15~35%, 기본 기대 점수 18~42점 (다수 봇이 6~25점대에서 조기 탈락하여 실제 유저의 승리 체감 대폭 향상).
  * **마스터 리그 봇 (1,000명)**: 승점 1,220~2,400 PT, 판수 80~350판, 승률 35~60%, 기본 기대 점수 55~95점 (고수다운 실력을 유지하되 후반 서든데스 구간에서 인간적 실수 유발).
* **리얼한 대기실 프로필 연출**: 국가 플래그 + 글로벌 닉네임 + 리그 배지 + 승점(`PT`) + 전적(`n전 n승`) + 연승(`🔥`)이 실시간 유저처럼 정교하게 표기된다.

### 6.5 직관적이고 웅장한 대형화 UI/UX 디자인
* **메인 화면 대형 프로필 & 레이팅 카드 (`.intro-profile-pill`)**:
  * 기존의 작고 답답했던 텍스트 바 형태에서 벗어나, **`⚡ 세계 8인 배틀` 버튼 바로 위에 808px 정폭(Full-Width) 아케이드 네이비 카드**로 대폭 확대.
  * **좌측**: 내 닉네임(46px 볼드 텍스트), 장착 스킨 아이콘, 클라우드 연동 상태(`☁️`), 리그 계급(`👑 마스터` / `🥈 일반`), 연승 배지(`🔥 n연승`), 나홀로 최고 점수 표시.
  * **우측**: **황금빛 대형 네온 배틀 점수(`64px` `1,050 PT`)**를 큼직하게 배치하여 로그인 직후 자신의 실력과 위상을 직관적으로 체감.
  * 카드 터치 시 언제든 Google / Apple 계정 연동 및 데이터 복원 모달 호출 가능.
* **8인 배틀 대기실 와이드 로스터 & 점수 강조 카드 (`.battle-player-list`)**:
  * 1080px 화면을 아낌없이 넓게 활용하도록 로스터 가로폭을 **기존 775px에서 `980px` 와이드 그리드로 전격 확장** (좌우 50px 여백).
  * **2열 × 4행(총 8명) 웅장한 배틀 카드 레이아웃** (`min-height: 154px`):
    * **상단 헤더**: 슬롯 번호(`1P`~`8P` 배지), 국기 및 플레이어 이름(`32px`), 장착 스킨 아이콘(`32px`), 본인 식별 배지(`ME`).
    * **중앙 스코어 라인**: 리그 엠블럼(`👑` / `🥈`)과 함께 **대형 승점(`50px` 볼드 `1,280 PT`)**이 한눈에 각인되도록 디자인.
    * **하단 스탯 라인**: 전적 태그(`14G 🥇5W`) 및 연승 엠블럼(`🔥 3연승`) 표기.
  * **나(ME) 카드 강조**: 눈에 띄는 네온 옐로우 그라데이션, 6px 블랙 보더, 핑크 입체 그림자, `ME` 레드 배지로 8명 중 자신을 단번에 식별.
  * **빈 슬롯 점유율 연출**: 아직 8명이 차지 않은 대기 상태에서는 `[4P ⏳ 매칭 대기 중...]` 점선 카드가 표시되어 전체 8명 중 현재 매칭 현황을 시각적으로 안정감 있게 전달.

## 7. 유저 프로필, 랭킹 및 보안 시스템

### 7.1 영구 닉네임 & 다국어 금칙어 필터
* **최초 1회 영구 등록**: 게임 시작 시 1회만 등록하며 변경 불가 경고(`⚠️ 한 번 등록한 이름은 절대 바꿀 수 없습니다`) 제공. (한글/일본어 최대 5자, 영문 최대 10자 가중치 제한)
* **금칙어 우회 방지**: NFD 유니코드 정규화, 리트스피크(`1`→`i`, `0`→`o`, `@`→`a` 등) 치환, 특수문자/공백 제거, 연속 중복 문자 압축을 거쳐 전 세계 주요 언어권 욕설/비속어/혐오 표현을 실시간 차단.

### 7.2 글로벌 & 국가별 TOP 1000 리더보드
* **1인 1최고기록 원칙**: 동일 유저가 여러 번 플레이해도 랭킹이 도배되지 않고 역대 최고 기록(Personal Best) 1개만 유지·갱신.
* **국가 자동 감지**: IP 기반 국가 코드를 판별하여 글로벌(`ranks`)과 자국(`ranks_country/{countryCode}`) 랭킹을 동시 지원.
* **어뷰징 방지 (`database.rules.json`)**:
  * 서버 규칙 레벨에서 `score` 정수 검증(1~3000), 최소 플레이 시간 검증(`playTimeMs >= score * 350`), 서명(`sig`) 필수 검증, 기존 점수보다 높을 때만 덮어쓰기 허용.

### 7.3 계정 연동 및 데이터 복원
* **Google ID / Apple ID 연동**: Firebase Auth를 통해 기기 변경 또는 앱 재설치 시 영구 닉네임, 개인 최고 점수, 대전 전적(총 판수/1위 횟수), 배틀 승점/연승/해금 스킨, 31번 언락 여부, 광고 제거 패스 구매 상태를 클라우드(`users/{accountKey}`)에서 그대로 복원.

## 8. 수익화 및 플레이 티켓 모델 (Monetization)

1. **초반 무료 온보딩**: 개인 모드에서 **31번 파이어볼을 최초로 돌파하기 전까지는 횟수 제한 없이 무제한 플레이**.
2. **일일 무료 티켓 (`DAILY_FREE_PLAY_LIMIT = 3`)**:
   * 31번 언락 이후 개인 모드: **하루 무료 3판** (서버 시간 기준 UTC 00:00 자동 리셋)
   * 온라인 대전 모드(세계 8인 배틀 / 친구와 특훈): **하루 무료 3판**
   * 로컬 날짜 조작 어뷰징 방지를 위해 서버 타임스탬프와 `DAILY_FREE_MAX_DAY_KEY`를 비교 검증.
3. **보상형 광고 & 인앱 결제**:
   * 무료 티켓 소진 시 **보상형 광고 1회 시청으로 1판 플레이** 가능.
   * **광고 제거 패스 (`$4.99` No Ads Pass)**: 구매 시 개인 모드 및 모든 온라인 대전 모드 평생 무제한 이용.
