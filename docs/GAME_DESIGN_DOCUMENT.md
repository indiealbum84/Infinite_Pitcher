## 3. 게임 메카닉 및 밸런스 설계 (Core Mechanics)

### 3.1 기본 규칙 (Number Matching)
1. 각 행은 **10개의 숫자**(1~10, 11~20, 21~30 ...)가 무작위 순서로 섞여 배치된다.
2. 플레이어는 **1번부터 오름차순으로 다음 정답 숫자(`nextExpectedNumber`)** 아래로 투수를 이동시켜 자동 투구되는 공을 맞혀야 한다.
3. **성공**: 점수 `+1`, 해당 블록 파괴, 다음 숫자 활성화, 블록판이 1줄 아래로 스크롤.
4. **실패**: 다른 숫자 블록을 맞히거나 빈 공간으로 공이 통과하면 즉시 **게임오버(Game Over)**.

### 3.2 투구 속도 가속 밸런스 (`getPitchInterval`)

#### ① 나홀로 특훈 & 친구와 특훈
| 구간 (다음 목표 번호 `n`) | 투구 간격 (Interval) | 체감 난이도 |
| :--- | :---: | :--- |
| `1 ~ 30` | **1,200 ms** (1.2초) | 입문 / 워밍업 |
| `31 ~ 130` | **1,000 ms** (1.0초) | 기본 템포 (파이어볼 입문) |
| `131 ~ 230` | **900 ms** (0.9초) | 가속 시작 |
| `231 ~ 330` | **800 ms** (0.8초) | 고속 영역 |
| `331 ~ 430` | **700 ms** (0.7초) | 초고속 영역 |
| `431 ~ 530` | **600 ms** (0.6초) | 극한 반사신경 |
| `531 ~ 630` | **500 ms** (0.5초) | 최상위 구간 |
| `631 이상` | **400 ms** (0.4초) | 마스터 한계 구간 |

#### ② 세계 8인 배틀 (방 전체 기준 가속)
특정 개인 유저가 아닌 **방 전체 기준(`getRoomSpecialBallCount`)** 으로 특수볼 출현 횟수를 산정하여, 초반 탈락자가 생겨도 남은 경기 전체가 동일한 템포로 100ms씩 가속된다. Phase 2~5 전환 간에는 최소 2구 간격을 보장한다.

| 페이즈 | 진입 조건 | 🥈 일반 리그 (`600 ~ 1,200 PT`) | 👑 마스터 리그 (`1,200 PT 초과`) | 발동 기믹 & 특징 |
| :---: | :--- | :---: | :---: | :--- |
| **Phase 1** | 게임 시작 (`1 ~ 10번`) | **`1,200 ms`** | **`1,000 ms`** | 일반 투구 워밍업 |
| **Phase 2** | `11번` 도달 | **`1,100 ms`** | **`900 ms`** | 🔥 **파이어볼** 개막 |
| **Phase 3** | 생존자 `5명 이하` OR `51번` 도달 | **`1,000 ms`** | **`800 ms`** | 🪞 **미러볼** 개막 (좌우 반전) |
| **Phase 4** | 생존자 `3명 이하` OR `91번` 도달 | **`900 ms`** | **`700 ms`** | 🦓 **스트라이프볼** 개막 (일반 리그 최종 단계) |
| **Phase 5** | *(마스터 전용)* 최후 `2인` OR `131번` | *(미출현 · 최저 600ms)* | **`600 → 400 ms`** | ⚡ **플래시볼** 개막 (숫자 점멸) |

## 5. 게임 모드 상세 기획 (Game Modes)

### 5.1 ⚡ 세계 8인 배틀 (World 8-Player Battle)
* **해금 조건**: **나홀로 특훈 31점 이상** 달성 시 해금.
* **실제 유저 우선 매칭**: 리그별 분리 큐(`_QP1` 일반 / `_QP2` 마스터)에서 **20초(`QUICK_MATCH_WAIT_SECONDS = 20`)** 동안 실제 유저를 우선 매칭하고, 만료 시 부족한 자리만 AI 챌린저 봇을 채워 **항상 8인 풀방**으로 시작.
* **최종 순위 확정 원칙**: 모든 참가자(봇 포함)를 **최종 점수 내림차순 + 올림픽식 공동 순위**로 판정한다. 최후 1인이 남더라도 이미 탈락한 참가자의 최고 점수(`maxDoneScore`)를 넘기 전까지는 경기를 조기 종료하지 않는다.
* **탈락 후 결과 & 조기 퇴장**: 탈락 시점에 현재 등수와 예상 레이팅(`1020 (-10)` 등)을 즉시 표시하며, 경기 완전 종료 전에 `돌아가기`를 눌러도 확정 등수 기준 레이팅이 정상 저장된다.

### 5.2 🧢 나홀로 특훈 (Solo Training Mode)
* 개인 최고 기록(Personal Best) 경신 및 글로벌/국가별 TOP 1000 랭킹 등재가 목표인 싱글 플레이 모드.
* 최초 31번 파이어볼 돌파 전까지는 무제한 무료 플레이 가능.

### 5.3 🤝 친구와 특훈 (Friend Training Mode)
* 4자리 방 코드 생성 및 입장. 솔로 모드와 동일한 가속(1,200ms → 1,000ms → 100구당 -100ms) 및 31+ 특수볼 규칙으로 친구와 가볍게 대결.

## 6. 8인 배틀 성장 & 동기부여 시스템

### 6.1 영구 배틀 계급(티어) & 제로섬 승점 시스템
* **시작 점수 & 범위**: 기본 **`1,000 PT`** 시작, 최저 **`600 PT`**, 최고 **`10,000 PT`** (DB 보안 규칙 상한).
* **순위별 승점 변동 (합계 `0`)**: `1위 +20` / `2위 +10` / `3위 +5` / `4위 0` / `5위 0` / `6위 -5` / `7위 -10` / `8위 -20`
* **리그 이원화**:
  * **🥈 일반 리그 (`600 ~ 1,200 PT`)**: 큐 `_QP1`
  * **👑 마스터 리그 (`1,200 PT 초과`)**: 큐 `_QP2`

### 6.2 연승 스트릭 (Win Streak)
* 8인 배틀 1위 시 `현재 연승 +1`, 2위 이하 시 `0` 초기화 (`최대 연승` 영구 보관). 2연승 이상 시 불꽃 배지 표시.

### 6.3 업적 기반 '컬렉션 (Collection)' (12종)
* 클래식 레트로 인쇄 스티커 배지 12종과 인게임 공 궤적·투수 오라 이펙트를 제공하며, 1회 해금 시 영구 소장한다.

### 6.4 리그별 1,000명 봇 풀 & 동시 투구 동기화
* **클라이언트 결정적 생성 (DB 비용 0원)**: 일반 1,000명 + 마스터 1,000명 봇 풀.
* **자연스러운 온라인 핸들 (80% 글로벌 / 20% 현지어)**: 실제 게이머 같은 닉네임과 20개국 국기를 사용하며, UI상 봇 구분 문구를 노출하지 않는다.
* **3대 티어(루키 30% / 중수 50% / 에이스 20%) + 3단계 방 난이도(쉬움 25% / 보통 50% / 어려움 25%)**.
* **동시 투구 동기화 (`syncBotsWithHumanPitch`)**:
  * 유저가 생존해 있는 동안에는 유저가 처리하는 공 번호에 맞춰 살아있는 봇들도 동일한 점수(자연스러운 `40~200ms` 반응 편차 포함)로 함께 진행하여, 특수볼 연출 등으로 봇과 점수 차이가 벌어지는 현상을 원천 차단한다.
  * 유저가 탈락한 뒤에는 남은 봇들이 인위적 가속 없이 정상 실시간 투구 간격(`getPitchInterval`)으로 끝까지 플레이한다.

## 7. 유저 프로필, 국적 고정 및 보안 시스템

### 7.1 영구 닉네임 & 다국어 금칙어 필터
* 최초 1회 영구 등록(한글/일본어 최대 5자, 영문 최대 10자). NFD 정규화·리트스피크 치환·다국어 금칙어 필터 적용.

### 7.2 최초 가입 국가 고정 (`homeCountry`) & TOP 1000 리더보드
* 이름 등록 전까지만 IP(`api.country.is`)로 국가를 감지하며, **최초 이름 등록 순간 해당 국가로 영구 고정**(`USER_COUNTRY_LOCKED_KEY`, 서버 `users/{accountKey}/country` 우선 유지)하여 VPN 등을 이용한 다국가 1위 중복 등록을 방지한다.
* 글로벌(`ranks`, `battle_ranks`) 및 자국(`ranks_country`, `battle_ranks_country`) TOP 1000 리더보드 지원.

### 7.3 Firebase 보안 규칙 (`database.rules.json`) & 계정 연동
* `ranks` / `ranks_country`: `score` 정수(1~3000), `playTimeMs >= score * 350`, 서명 검증, 최고점 갱신만 허용.
* `users` / `battle_ranks` / `battle_ranks_country`: 이름 변조/삭제 불가, `bestScore <= 3000`, `battleRating 600~10000` 정수 검증.
* Google ID / Apple ID 연동 시 닉네임·국적·최고기록·컬렉션·구매 내역·배틀 레이팅을 클라우드(`users/{accountKey}`)로 동기화·복원한다.
