# 게임 UI 디자인 백로그

2026-11-27 운영 빌드 `0ee99bf`에서 캡처한 26개 화면과 상태를 추적한다.

## 첫 작업 · 공통 팝업 11개

게임 소스에 적용했다. 11개 상태의 실제 화면을 적용 전후로 비교했다.

8인 배틀 리그 정보 팝업의 크림색 바탕, 남색 테두리와 그림자를 기준으로 삼는다. 팝업의 딤, 제목과 닫기 위치, 여백, 버튼 위계, 스크롤 동작을 맞춘다. 콘텐츠가 긴 팝업은 본문을 스크롤하고 제목과 닫기는 고정한다. 확인창은 짧은 본문 아래에 명확한 행동 버튼을 둔다.

### 짧은 확인·알림 · 4개

- [x] 로비 복귀 확인
- [x] 공통 알림
- [x] 광고 제거 구매 확인
- [x] 계정 복원 이메일 입력

공통 알림, 구매 확인, 이메일 입력은 같은 `#game-dialog`를 쓰는 세 상태다. 로비 복귀 확인에도 같은 시각 규칙을 적용한다. 버튼은 화면에 따라 ‘돌아가기’, ‘구매’, ‘확인’처럼 행동을 표시한다.

### 목록·정보 팝업 · 7개

- [x] 설정
- [x] 설정 언어 목록 펼침
- [x] 배지 컬렉션
- [x] 특수볼 가이드
- [x] 메인 랭킹 · 8인 배틀 탭
- [x] 메인 랭킹 · 개인 특훈 탭
- [x] 개인 특훈 결과 · 랭킹 팝업

설정 언어 목록은 설정 안의 상태다. 메인 랭킹 두 탭은 같은 팝업에서 다루고, 결과 랭킹과는 헤더·탭·목록의 스타일을 공유한다. 컬렉션의 배지 그리드와 특수볼 가이드의 설명 카드는 각 콘텐츠에 맞게 배치한다.

**완료 확인**

작은 모바일 화면에서도 제목·닫기·주요 버튼이 보인다. 긴 목록을 스크롤할 수 있고 팝업을 닫으면 열었던 버튼으로 포커스가 돌아간다. 이메일 입력 시 키보드와 입력칸이 겹치지 않는다. 랭킹 탭 전환, 설정 변경, 배지 선택과 구매 확인 동작을 확인한다.

## 완료 · 플레이·구매 팝업 4개

- [x] 플레이·구매 정보
- [x] 개인 특훈 무료 플레이 소진
- [x] 배틀 무료 플레이 소진
- [x] 8인 배틀 해금 안내

무료 이용 현황은 야구공 세 개로 표시하고, 소진 시 다음 충전까지 남은 시간을 보여준다. 광고 제거 배너에는 가격과 두 모드의 무제한 혜택을 함께 표시한다. 구매 후에는 로비와 팝업에 무제한 상태가 표시된다. 해금 안내는 31점 돌파 패치와 로비 출전 안내를 일러스트 하단에 배치한다.
